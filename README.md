# DevOps Hands-on Projects

## Objective

Build DevOps skills using Azure, Linux, Terraform, GitHub Actions, Docker and Kubernetes.

## Projects

### 1. Linux VM Deployment
- Azure Linux VM provisioning
- Network and NSG configuration
- Application deployment
- Linux service management
- Application troubleshooting

### 2. Terraform Automation
- Infrastructure as Code
- Azure resource provisioning
- Remote state management
- Terraform modules
- State locking and drift management

### 3. Docker
- Dockerfile creation
- Image building
- Container management
- Container troubleshooting

### 4. Kubernetes
- Deployments and Services
- ConfigMaps and Secrets
- Ingress
- Health probes
- Rolling updates and rollback

### 5. GitHub Actions
- CI/CD workflows
- Automated builds and tests
- Deployment automation
- Secure authentication using OIDC
